Daylight — the light twin of Aurora
Same token names, same rules, inverted values: one hero card per screen carries the sky→leaf tint, everything else is a white card on the brand background gradient. The two real fixes for light mode are contrast-specific — brand sky blue only reaches 2.2:1 on white, and the DS faint ink only 3.1:1, so light mode gets its own deepened text blue and metadata ink. Layouts, copy and the tab-bar structure are unchanged. Includes the two screens that weren't in the dark set: Stats and the Our Story share card.

IMPLEMENTATION RULES — LIGHT
Text ramp
text-1 #16232F — titles, values, list labels · ≈15:1 on white
text-2 #52657A — supporting copy, row labels · ≈7:1
text-3 #6C7F8D — eyebrow and metadata only · ≈4.7:1
The DS --faint-ink #8695A3 is 3.1:1 on white and must not be used for text — that's what text-3 replaces.
Blue is inverted from dark
Sky blue #4FA9E0 is 2.2:1 on white — never text. Light-mode text blue is #1F6F9E (≈5.5:1); fills use #2F82BE so white content on them clears 4.5:1. Same two-blue rule as dark, opposite direction.
Green and red deepen too
Answer text uses #1E7A4B and #C2334A, not the brand mid-tones. Tints stay at brand hue — the 14–18% chips are backgrounds only, never a text colour.
One gradient per screen
Same rule, inverted: --hero-surface is white lifted with a sky→leaf whisper, and only the screen's primary object gets it. Every other card is plain white.
Elevation
Light mode inverts the dark rule: shadow does the work a hairline does on dark. One shadow token (0 10px 30px rgba(28,42,56,.10)) on every card, plus a 10% hairline for edge definition on tinted backgrounds.
Shared with dark
Identical token names, so a screen is written once and themed by scheme. Colour roles, states (pressed +6%, disabled 55%, 2px focus ring), radii (26 / 16 / 999) and the 110px tab-bar content inset are unchanged.
