IMPLEMENTATION RULES
Text ramp
text-1 #F3F7FA — titles, values, list labels · ≈15:1
text-2 #AEC0CD — supporting copy, row labels · ≈8.5:1
text-3 #8295A5 — eyebrow labels and metadata only, never sentences · ≈5:1
Nothing below 4.5:1 is used for text at any size.
Colour roles, locked
Blue = interactive, live, in-progress. Green = matched, completed, together. Red = destructive, love, unread badge. A hue never appears decoratively — if it carries no state, it's a neutral surface.
Two blues, on purpose
Brand #4FA9E0 is only a fill — buttons, toggles, route lines, badges — with white on top. Text and icons use the lightened #8ACFF5, which clears 9:1 on card surfaces. Brand blue as text on dark was most of the old contrast debt.
One gradient per screen
Only the screen's primary object gets --hero-surface: the tracked flight, the streak card, the score. Two heroes on one screen means neither is one. Screens with no primary object stay entirely flat.
States
Pressed: surface +6% white overlay, no scale. Disabled: text-3 at 55%, surface unchanged. Focus: 2px #8ACFF5 ring at 2px offset. Selected: accent chip background plus accent text, never a filled block.
Elevation & chrome
Depth comes from three surface steps plus a 1px hairline; shadows only under the hero card and the tab bar. Tab-bar structure is unchanged but near-opaque with blur, and every scroll view reserves 110px bottom inset so the last row is never clipped.
